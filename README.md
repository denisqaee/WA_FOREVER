# WA_FOREVER

Ауры для **ForeverAuras** (форк WeakAuras для WoW Forever).

Каждый `.txt` содержит одну строку импорта `!WA:2!...`.
Импорт: открыть файл → скопировать всё → в игре `/fa` → Import → вставить.
Если аура с таким именем уже есть, ForeverAuras предложит обновить её.

| Аура | Что делает |
|---|---|
| [Освобожденный гнев — смена печати](Паладин/Освобожденный%20гнев%20—%20смена%20печати.txt) | Талант «Освобожденный гнев»: точки-стаки Отголосков (слева повиновение, справа праведность); при 3 стаках загорается иконка печати, на которую пора переключиться, — только если эта печать ещё не стоит. ## tools
`tools/wacodec.py` — кодирование и раскодирование строк `!WA:2!` (LibDeflate + LibSerialize) на Python:

```python
from wacodec import decode, encode
data = decode(open("Воин/Превосходство.txt").read())   # -> dict
text = encode(data)                                      # -> "!WA:2!..."
```

Сделано с помощью Claude. Строки проверены декодированием; в игре — по мере тестов.
